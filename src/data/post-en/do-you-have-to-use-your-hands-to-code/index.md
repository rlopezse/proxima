This week, while I was setting up (again) Ghostty with Neovim and tmux, I realized (again) that my workflow had turned into 90% Claude Code and 10% reviewing and writing code.

Because of that, at some point I thought tmux was going to become useless for me, since I no longer had 2 panes open per tab, just a single one controlling Claude Code. So I wondered if it was time to switch tools (again), from Ghostty to something more agent-oriented. The downside of this terminal is that when an agent finishes working it doesn't notify you, the links it gives you aren't dynamic, and you have to go hunting 1 by 1 for what changed, which commands it ran, etc.

### Warp and cmux

First I went for Warp, because I think it looks nice and the name is awesome, very space-y, just how I like it. But after using it for about 30 minutes it didn't click with me: it was just another VS Code fork, so out it went.

Then I tried cmux. This one was better, 100% agent-oriented, with an interface just like the one I pictured in my workflow. But I felt it was missing something: it was still a tmux in another place, I still had to go look for where the changes were made, and it wasn't what I was looking for.

### T3 and building your own software

While I was making my wife's birthday breakfast, I thought that with all this AI stuff, at some point software might become so "democratic" that everyone has their own programs. I have my code editor, someone else has theirs, and so on, a level of customization that goes far beyond just changing the editor's color and font.

And I remembered that Theo from [T3](https://t3.gg/) went through something similar and ended up building a tool inspired by cmux, a hybrid between that and the interface of AI chats (ChatGPT, Claude, etc.). After trying it out, I liked it. It's a beta, but it's more or less what I imagined: a status window, commands being run, edited files, diffs, clickable links, etc. Something good for this whole transition toward agents.

### Do you have to use your hands?

There's a scene that keeps coming back to my mind. It's from Back to the Future Part II: they're in a diner and some kids want to play Wild Gunman, but they don't know how to use it. Then Marty McFly walks up, grabs the gun, plays, and wins the game. The kids, with astonished faces, say to him: "You mean you have to use your hands? That's like a baby's toy!"

I feel like that's where software is headed (if we aren't there already). I still think everything is moving very fast, but on the other hand I think we're in the golden age of software, where knowledge isn't a barrier to generating ideas, and all it takes is the desire to create.

Maybe in a few years it will seem as strange to us that we wrote every line by hand as it did to those kids to see someone playing with their hands. And if that's the case, perhaps what will matter most is no longer how we write code, but what we decide to build with it.
